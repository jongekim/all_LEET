# LEET 문제지 워터마크 PDF 78개

문구: `리트 채점은 all LEET`

모든 1,292쪽의 하단 중앙에 9pt, RGB 0.78의 연한 회색으로 넣었다. 원본 하단의 삽입 영역이 비어 있음을 페이지별 렌더링으로 확인했다. 원본 파일명과 페이지 크기·쪽수는 유지하며, 원본은 상위 폴더에 보존한다. 사용자가 교체한 2017 언어이해 짝수형도 포함한다.

파일별 원본·출력 SHA-256은 `files.json`과 `files.csv`에 기록했다. 서비스 제공 경로나 배포는 이 작업에서 수정하지 않았다.

검증 완료: 78개 · 1,292쪽. 모든 페이지에 워터마크가 표시되며, 삽입 영역 외에 내용 변경이 없는지 이미지 비교와 추가 PNG 재검사로 확인했다. 첫쪽·마지막쪽 및 각 파일의 확대 워터마크를 육안 검토했다. 압축과 불필요한 데이터 정리는 페이지 콘텐츠 바이트를 바꾸지 않는다. 원본 78개의 SHA-256도 일치한다. 상세 결과는 `verification.json`에 기록했다.
