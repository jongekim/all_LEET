# 기출문제·정답표

`/past-exams`는 로그인 없이 조회할 수 있다. 학년도·과목·문형은 URL의 `year`, `subject`, `type`으로 유지한다. 학년도 목록은 정답과 문제지 학년도의 합집합이고 기본값은 2027학년도다. `09예비`는 별도 항목이다.

검색 유입용 `/past-exams/2009`~`/past-exams/2027`은 학년도별 고정 URL이다. 각 페이지의 초기 HTML에 해당 학년도의 두 과목 PDF 링크와 문형별 정답표, 실제 문항 수·문형·PDF 개수를 넣는다. 2009~2026학년도는 공개 통계의 문항별 정답률을, 2027학년도는 검색용 통계 미발행 안내를 제공한다. 정답률·환산표를 보는 대화형 `/past-exams?year=...` 경로도 연결한다. `/question-rates`는 정답률의 의미와 한계를 설명하고 2025학년도 홀수형 두 과목의 공개 비율을 초기 HTML에 제공하며, 기존 `QuestionStatistics` UI를 기본 2025학년도 정답표와 함께 펼쳐 제공한다. 검색용 비율은 `src/data/seoQuestionRates.json`에 기록된 공개 발행본의 읽기 전용 복제본이므로 발행일·조합별 표본 수를 표시한다. 통계가 새로 발행되면 요약 파일을 갱신하고 웹앱을 다시 배포해야 한다. 숫자 학년도 고정 URL만 사이트맵에 포함하며 `09예비`는 기존 선택 UI에서 계속 조회한다.

## 제공 중인 문제지

09예비 및 2009~2026학년도 두 과목의 홀수형·짝수형 76개와 2027학년도 단일 문형 두 과목 2개, 총 **78개 모두 워터마크 PDF**로 제공한다. 워터마크는 하단 중앙의 연한 회색 문구 `리트 채점은 all LEET`이다. 2017 언어이해 짝수형은 사용자가 교체한 정상 PDF를 기준으로 한다. 같은 파일을 다른 문형으로 복제하지 않는다.

`pastExamDocuments.ts`는 [Storage 업로드 기록](../output/pdf/watermarked/supabase-upload-records.json)의 공개 URL·파일명·실제 용량으로 등록한다. 열기는 공개 URL을 새 탭에서 열고, 다운로드는 `?download=<파일명>`으로 Storage의 attachment 응답을 사용한다. 브라우저의 교차 출처 download 속성 제한에도 실제 파일 저장이 가능하다. 출처 링크 및 HWP 뷰어 안내는 표시하지 않는다.

문제지 아래에 “전개년·전과목 문제지는 모두 PDF로 제공합니다.” 및 “법학적성시험 문제의 저작권은 법학전문대학원협의회에 있습니다.”를 표시한다. 확보 경위와 원본 해시는 [원본 보관 기록](past-exam-files.md)에 유지한다. 이전 정적 원본은 `downloads/past-exams-original-archive/`에 보존하고 빌드에 포함하지 않는다.

2027학년도는 `단일 문형 (홀수형·짝수형 구분 없음)`으로 표시한다. `type=even`도 기본 `type=odd`로 보정하지만 등록된 PDF는 `examType: 'single'`로 조회한다. 제목·파일명을 홀수형으로 표시하지 않는다. 채점 화면도 2027학년도를 지원하고 단일 문형을 표시한다. 기존 이력과 호환되도록 내부 유형은 `odd`를 사용하며 두 내부 문형의 정답은 같다.

## 화면과 정답표

기존 PageHeader와 파란색 강조를 사용한다. 선택·문제지·정답표·환산표는 같은 테두리·둥근 모서리·간격을 사용한다. 모바일에서는 학년도를 한 줄, 과목·문형을 두 열로 배치하며 PDF 열기·다운로드 버튼은 같은 너비로 표시한다. 버튼은 최소 44px 높이와 키보드 포커스를 유지한다.

정답표·환산표는 문제지 아래의 카드를 직접 눌러야 함께 표시한다. 기본은 접힘이며 시험 선택 변경, 뒤로가기·앞으로가기, 새로고침 시 다시 접힌다. 펼침 상태는 저장하지 않는다. 정답은 기존 `answerData.ts`, 문항 수는 `getQuestionCount()`, 환산표는 `scoreData.ts`를 사용한다. 환산표는 만점부터 0개까지 표시하며 홀수형·짝수형 공통이다. 추정값을 안내하고 미등록 구간은 `—`로 표시한다. 2027학년도도 정답·환산표를 제공한다. 출처와 빈 구간 추정 방식은 [2027 채점 데이터](grading-2027.md)를 따른다. 공개 통계가 미등록이면 통계 준비 중 안내를 표시하며 정답·환산표는 유지한다.

## 문제지 등록 및 정정

1. 학년도·과목·문형 및 파일 내용을 확인하고 원본 확보 기록을 남긴다.
2. PDF로 변환한 뒤 워터마크를 넣어 검증하고 공개 Storage의 새 버전 경로에 올린다. 기존 캐시 파일을 덮어쓰지 않는다.
3. 공개 다운로드의 PDF 헤더·MIME·용량·SHA-256을 확인하고 `pastExamDocuments.ts`에 PDF 공개 URL·파일명·용량을 등록한다. 업로드 기록과 문서를 함께 갱신한다.
4. 수정 직후에는 관련 단위 테스트와 공개 파일 다운로드만 확인한다. 전체 E2E를 포함한 `npm run check`는 웹앱 배포 직전에 실행한다. `main` push는 실서비스 배포를 시작하므로 사용자의 명시적인 요청 후 실행한다.

등록 항목의 형식은 `format: 'pdf'`로 제한한다. URL·학년도·과목·문형 매칭은 단위 테스트에서 업로드 기록과 비교한다. 아직 확보하지 못한 파일이나 다른 문형의 파일을 등록하지 않는다. 2027 채점 데이터 추가는 정적 정답·환산 테이블을 갱신하며 기존 Storage 객체·RLS·인증·DB 스키마는 변경하지 않는다.

## 검증

Vitest에서 78개 모두 업로드 기록의 워터마크 PDF URL·파일명·실제 용량과 일치하는지 확인한다. 기존 정답 조합 및 URL 선택 보정 테스트를 유지한다. Playwright에서 전개년·전과목·전문형 78개 선택, 출처 제거·PDF/저작권 안내, 모바일 및 단일 문형 PDF 다운로드, 정답표 접기·키보드 접근성, 320/390/1280px 가로 넘침을 확인한다. 화면 자동화의 Supabase 및 다운로드 요청은 모의 처리하고 공개 파일의 실제 응답 검증은 읽기 전용으로 별도 실행한다.
