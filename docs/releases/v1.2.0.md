# v1.2.0 — 문항별 공개 정답률

릴리스 준비일: 2026-09-17. 기존 흐름과 호환되는 사용자 기능 추가이므로 MINOR 버전을 올린다.

## 변경 내용

- 채점 후 결과와 펼친 기출 정답표에서 문항별 정답률을 제공한다.
- 응답 분포 모달에 1~5번·미응답의 퍼센트만 표시한다. 기록 수·응답 건수·집계 일자는 숨긴다.
- 30건 이하 데이터 부족 경고와 짝수형 다회독 안내를 제공한다.
- 문항 행 간격과 정답표 카드 UI를 개선하며 기존 정답 보기·메모·접기·환산표를 유지한다.
- DB에 보존한 발행본을 공유하며 개발자 수동 갱신·검증·롤백 도구와 운영 규칙을 추가한다.

## 배포 전 검증

- 버전 일치 검사 및 `npm run check` 통과: 단위 테스트 108개, Playwright 화면 테스트 27개, lint 오류 0건, 타입 검사·빌드 성공.
- 격리 PostgreSQL 테스트 통과: 미응답·부분 답안, 76개 조합, 원자적 발행, 중복 발행, CAS, 롤백, anon/authenticated 권한 거부.
- 운영 읽기 전용 검증: 적용 마이그레이션 체크섬 일치, 신규 5개 테이블 RLS, 공개 SELECT 전용 권한, 비공개 함수 실행 차단, 76개 공개 조합과 현재 정답표·분포 호환성 확인.
- 실제 데이터 화면 검증: 언어이해 1번 홀수 78.3%·짝수 86.8%, 추리논증 34번 홀수 36.1%·1번 짝수 64.5%. 선택률 6개·짝수 안내·날짜 숨김·320px 모바일 화면 확인. 운영 쓰기 요청 0건.
- 남은 기존 경고: lint 74건, 번들 크기 경고, Supabase 보안·성능 WARN 45건. 신규 통계 기능 관련 advisor 경고·ERROR는 없다. 이력 API 인증 개선은 이전 결정대로 별도 과업이다.

## 운영 영향

`main` push가 Vercel 웹 배포를 시작한다. 최초 DB 구조와 발행 ID `1`(76조합·5,716건)은 이미 적용되어 있으므로 DB 마이그레이션 재실행·재집계·Edge Function 배포는 하지 않는다. 원본 이력·인증·개인 메모는 변경하지 않는다. 통계 갱신/롤백은 [수동 갱신 가이드](../question-statistics.md)를 따른다.

push 후 Vercel 상태와 실서비스의 두 과목·홀수형/짝수형 공개 화면을 확인한다. Vite 캐시·Supabase CLI 임시 파일은 릴리스 커밋에서 제외한다.
