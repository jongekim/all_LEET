# 문항별 정답률 제공 설계 및 구현

## 확정 사항

- 표시 위치는 **채점 후 결과(`/result`)**와 **기출문제·정답표(`/past-exams`)의 펼친 정답표**다. 답안 입력 화면에는 정답률을 노출하지 않는다.
- 기록 수와 무관하게 공개한다. **30건 이하(30 포함)**에는 데이터가 충분하지 않아 정답률 정확도가 떨어질 수 있다는 안내를 표시한다. 공개 최소 건수는 없다.
- 사용자 화면에는 1~5번 선지와 미응답을 각각 **퍼센트만** 제공한다. 실제 채점 기록 수·선지별 응답 건수는 표시하지 않는다. 30건 이하 경고는 유지한다. DB와 개발자 갱신 도구는 계산·검증용 건수를 보존한다. 미응답은 정답률 계산에서 오답이며 분모에서 제외하지 않는다.
- 서버가 주기적으로 계산하지 않는다. 최초 집계 후 DB 발행본을 여러 화면이 공유하고, 개발자가 필요할 때 수동으로 전체 교체한다.
- 기존 성적 이력 API의 인증·인가 보완은 사용자 요청에 따라 별도 과업으로 보류했다. 이번 기능은 해당 API·원본 KV·메모를 수정하지 않는다.

이 문서는 이전 설계의 최소 표본 비공개, 30건 미만 경고, 보안 보완 선행 조건을 대체한다. 실제 운영 명령과 검증 절차는 [수동 갱신 가이드](question-statistics.md)를 따른다.

## 집계 단위와 수식

`학년도 × 과목 × 홀수형/짝수형 × 해당 문제지 문항 번호`로 구분한다. 유형 간 문항 매핑을 가정하거나 합산하지 않는다. 2026~2009 및 09예비의 19학년도, 2과목, 2유형 = 76개 조합을 매번 함께 발행한다.

집계 규칙 버전은 `all_saved_records_v1`이다.

- 원본: `public.kv_store_cd835c22`의 `history:%` JSON 배열. `mock_history:%`는 제외한다.
- 배열의 과목별 기록 1개가 표본 1건이다. 회독·재채점·동일 답안·부분 답안을 모두 포함한다. 고유 사용자 수나 실전 응시자 수를 뜻하지 않는다.
- 문항의 키 누락, JSON null, 숫자 0은 미응답이다. `userAnswers` 전체가 누락/null이어도 전 문항 미응답으로 포함한다.
- 정답표·문항 수는 현재 저장소의 `ANSWER_DATA`·`getQuestionCount`가 기준이다. 저장된 `correct` 또는 과거 `correctAnswers`로 계산하지 않는다.
- 알 수 없는 학년도/과목/유형, 잘못된 답안 객체·문항 키·선지 값, 배열이 아닌 이력 값이 나오면 **임의로 제외하거나 고치지 않고 prepare/발행을 중단**한다. 별도 원인 검토가 필요하다.

문항마다 `choice_counts[0..4] + unanswered_count = sample_count`를 검증한다.

```text
정답률 = 정답 선지의 선택 건수 / 전체 채점 기록 수 × 100
선지·미응답 비율 = 해당 선택·미응답 건수 / 전체 채점 기록 수 × 100
```

비율은 화면에서 소수점 한 자리로 계산한다. 반올림으로 6개 비율 합계가 정확히 100%가 아닐 수 있다. 표본 0건은 0%가 아니라 모든 비율을 `—`로 표시한다. 건수는 화면·접근성 라벨·툴팁에 표시하지 않는다. 이는 UI 표시 정책이며, 공개 집계 API의 기존 계산용 건수를 제거하는 권한/스키마 변경은 아니다.

## 데이터 구조와 권한

| 위치 | 객체 | 역할 |
|---|---|---|
| private | `exam_answer_key_versions` | 학년도·과목·유형별 정답 버전과 최근 publish에서 등록한 활성 버전 |
| private | `exam_question_answer_keys` | 버전별 문항 정답 |
| private | `question_statistics_runs` | 발행 ID, 원본 시각, 건수, 체크섬, 집계 파일, 수행자·사유·발행/롤백 이력 |
| public | `question_statistics_snapshots` | 발행 세대별 시험 조합의 전체 문항 분포 |
| public | `question_statistics_publication` | `key='current'`인 현재 발행 ID 한 개 |

스냅샷 PK는 `(snapshot_id, year, subject, exam_type)`이다. 문항 분포는 문항 번호순 `items` JSONB로 저장한다. 선택 5개·미응답의 비음수 안전 정수 여부와 합계를 DB CHECK 및 프론트/도구에서 검증한다.

정답 버전은 `v1:` 뒤에 문항 순서대로 정답 숫자를 연결한 **내용 지문**이다. 암호학적 해시가 아니며 과목·유형·학년도와 함께 사용한다. 파일 무결성은 별도의 SHA-256 `artifact_checksum`으로 검증한다.

공개본의 정답 버전은 해당 스냅샷의 `answer_key_version`으로 판단한다. rollback은 등록 정답 버전을 수정하지 않으므로 정답 레지스트리의 `is_active`와 과거 공개본이 다를 수 있다. 조회는 `is_active`에 의존하지 않는다.

모든 신규 테이블은 RLS가 켜져 있다. `anon`·`authenticated`는 공개 두 테이블의 SELECT만 가능하며, 스냅샷은 현재 포인터의 세대만 볼 수 있다. 이전 발행본·개별 사용자 답안·사용자 ID·수행자 정보는 공개하지 않는다. 공개 INSERT/UPDATE/DELETE 및 발행/롤백 RPC는 없다. 개발자 도구는 브라우저와 분리된 Management API 인증을 사용한다.

`private.publish_question_statistics`와 `private.rollback_question_statistics`는 **SECURITY INVOKER**, 빈 `search_path`이며 PUBLIC/anon/authenticated/service_role의 EXECUTE를 취소한다. 서비스 키를 새로 도입하지 않는다.

## 수동 갱신의 일관성

1. prepare는 한 SQL 문의 MVCC 스냅샷에서 집계한다. DB에서 나오는 값은 집계 결과뿐이며 개별 사용자 기록을 파일로 내려받지 않는다.
2. 76개 조합·문항 수·정답 버전·6개 분포 합계·전체 건수를 검증한 파일을 생성한다. 기존 파일은 덮어쓰지 않는다.
3. 개발자가 기록 수·분포·대상 프로젝트를 검토한 뒤 publish한다. 파일 생성 이후의 신규 기록은 다음 갱신에 포함된다. 발행 시 원본을 재집계하지 않는다.
4. 트랜잭션 advisory try-lock과 `expected-current`로 동시 발행·잘못된 덮어쓰기를 막는다.
5. 정답 등록·집계 기록·76개 스냅샷·현재 포인터를 **한 트랜잭션**으로 저장한다. 검증/저장 실패 시 부분 발행하지 않는다.
6. 같은 체크섬·내용의 파일이 이미 현재 세대라면 성공한 기존 ID를 반환한다. 이전 파일을 다시 공개하려면 명시적인 rollback을 사용한다.
7. rollback은 보존된 완전한 세대만 가리키도록 포인터를 바꾸고 감사 이력을 기록한다. DB 구조·원본 이력·저장된 정답을 삭제하지 않는다.

cron, trigger, Edge Function 배포, 저장 이벤트 연동, 정기 실행, 발행본 자동 삭제는 없다. 원본 삭제나 정답 변경을 공개 수치에 반영해야 할 때에도 개발자가 전체 갱신한다.

## UI/UX 및 조회

- 짝수형에만 "짝수형은 다회독 데이터가 많아 실제 정답률보다 높게 나타나는 경향이 있습니다."라는 안내를 결과/정답표의 공통 정답률 영역과 응답 분포 모달에 제공한다. 홀수형에는 이 안내를 표시하지 않는다. 집계 방식이나 비율은 보정하지 않는다.
- 집계 일자는 사용자 화면·접근성 라벨·툴팁에 노출하지 않는다. DB의 원본 조회/발행 시각과 개발자 도구의 감사·검증 정보는 유지한다.

- 결과 화면은 답안 아래 별도의 정답률 버튼을 유지하고, 문항 행 간격을 8px에서 16px로 늘려 위·아래 행의 정답률을 구분한다. 가로 간격·문항 수는 바꾸지 않는다.
- 정답표는 흰 문항 카드에 문항 번호·정답을 표시하고, 얇은 구분선 아래 퍼센트·화살표로 선택률 진입을 제공한다. 문항별 반복 '정답률' 라벨과 중첩 파란 버튼은 사용하지 않는다. 정답률 의미는 상단 공통 안내와 각 버튼의 접근성 라벨로 제공한다.
- 정답률을 누르면 1~5번·미응답의 퍼센트를 표시하는 6행 모달을 연다. 정답 선지를 텍스트와 색으로 표시하고, 학년도·과목·유형을 함께 보여준다. 실제 기록 수·선지별 응답 건수는 화면 어디에도 표시하지 않는다. 기존 답안 표시·정답 확인·메모는 유지한다.
- Radix Dialog를 사용해 키보드 접근, 포커스 제한, Escape 닫기, 트리거로 포커스 복귀를 제공한다. 자체 CSS로 모바일 위치·배경·스크롤을 보장한다.
- 정답표는 기존처럼 기본 접힘이고 시험 선택을 바꾸면 다시 접힌다. 통계를 위해 미리 정답표를 펼치지 않는다.
- 결과의 오답 정답 보기 2초 유지, 문항 메모·전체 메모 버튼, PDF·환산표 기능은 유지한다. 통계 버튼을 눌러도 정답 보기·메모를 실행하지 않는다.
- 조회 중·미발행·오류·정답 버전 불일치 상태를 구분한다. 통계 오류에는 재시도를 제공하며 기존 답안·정답표·메모는 계속 사용할 수 있다.
- 과거 결과의 저장 정답이 현재 정답과 다르거나 없으면 통계를 함께 표시하지 않는다. 개인 결과를 현재 정답으로 다시 채점하지 않는다.
- 동일 학년도·유형의 두 과목은 한 SELECT와 공유 요청으로 읽는다. 5분 캐시와 만료 후 창 포커스 재조회로 수동 발행 변경을 반영한다. 즉시 확인은 새로고침한다. 선택 변경 후 늦게 도착한 응답은 해당 화면에 적용하지 않는다.
