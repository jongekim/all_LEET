# 2027학년도 채점 데이터

2026-09-19 사용자가 제공한 언어이해 정답표, 추리논증 정답표, 원점수·표준점수·백분위 표 이미지 3개를 기준으로 등록했다. 정답 30문항·40문항은 모두 제공 자료를 전사했다. 환산표의 발행 기관·공식 여부는 별도로 확인되지 않았으므로, 제공 자료 값과 추가 추정값을 구분하며 공식 확정 환산표라고 표현하지 않는다.

## 지원 동작

홈의 기본 학년도를 2027로 설정하고 채점을 활성화했다. 2027은 단일 문형으로 표시하며 유형 선택을 제공하지 않는다. 과거 학년도에서 2027로 전환하면 답안을 비우고 내부 유형을 `odd`로 정규화한다. 기존 `ExamType`, 이력 API 및 DB 스키마와 호환되도록 단일 문형 정답은 `odd`·`even`에 동일하게 보관한다. 결과·이력·통계 모달의 문형 표시는 2027에 한해 단일 문형이다.

기출문제 화면에서도 정답표와 환산표를 제공한다. 각 과목의 만점부터 0개까지 누락 없이 환산한다. 사용자가 추가 제공한 시행결과의 분야 분류를 `fieldMapping`에 등록해 두 과목의 분야별 분석을 제공한다. 과거 시험의 분야 분석은 유지한다.

## 분야 분류

## 제공된 환산값

- 언어이해: 18~29개 표준점수·백분위.
- 추리논증: 23~38개 표준점수·백분위, 21개 표준점수 54.3.
- 그 밖의 값은 추가 추정이며 `estimatedStandardScore`, `estimatedPercentile`로 각각 구분한다. 환산표 셀의 title과 기존 추정값 안내, 2027 채점 결과의 추정값 안내를 제공한다.

## 빈 구간 추정

표준점수는 과목별 제공된 연속 구간의 양 끝점으로 기울기를 계산해 선형 보간·외삽하고 소수점 첫째 자리로 반올림한다. 제공된 값은 덮어쓰지 않는다.

- 언어이해: `45.3 + (맞은 개수 - 18) × (69.3 - 45.3) / (29 - 18)`.
- 추리논증: `58.4 + (맞은 개수 - 23) × (89.5 - 58.4) / (38 - 23)`.
- 언어 만점 71.5, 추리 만점 93.6, 추리 22개 56.3. 추리 21개는 제공값 54.3을 유지한다.

하위 백분위는 기존 데이터처럼 낮은 점수에서 0으로 수렴하도록 정규 누적분포를 이용해 추정한다. 제공된 최하위 6개 구간(언어 18~23개, 추리 23~28개)의 백분위를 정규분포 z값으로 변환하고 `z = a × 맞은 개수 + b`를 최소제곱으로 적합한다. 표준편차는 `1/a`이며, 평균은 제공된 최하위 구간의 백분위를 정확히 통과하도록 `최하위 맞은 개수 - 표준편차 × 최하위 z값`으로 설정한다.

- 언어: 평균 `18.087248819354226`, 표준편차 `3.867143358350367`.
- 추리: 평균 `24.08340163661276`, 표준편차 `5.652405367240293`.
- 빈 하위 구간은 `100 × Φ((맞은 개수 - 평균) / 표준편차)`를 소수점 첫째 자리로 반올림한다. 언어 17개 38.9, 16개 29.5; 추리 22개 35.6, 21개 29.3.
- 제공된 최고 구간을 초과하는 언어 30개, 추리 39~40개의 백분위는 기존 데이터의 상한 처리처럼 100.0으로 추정한다.

이는 공식 빈도 분포를 복원한 값이 아닌 참고용 추정이다. 결과는 정적 테이블에 저장해 런타임의 환산이 일관되도록 한다.

## 검증 및 운영

`src/utils/grading2027.test.ts`에서 첨부 정답·환산값 전사, 0개~만점 채점, 두 내부 문형의 동일 정답, 추정 구간 누락·범위·단조성과 분야별 문항 배정·정답 수 합계를 확인한다. `e2e/past-exams.spec.ts`에서 2027 홈 입력, 과거 문형에서 전환, 정답표·환산표, 320px 배치와 단일 문형 PDF 연결을 확인한다. `e2e/past-exams.spec.ts`의 2027 분야별 결과 화면 검증은 navigation state에 로컬 채점 결과를 주입해 5개 분야와 정답 수를 확인한다. Supabase 요청은 모의 처리하고 운영 이력 제출은 실행하지 않는다.

DB·Storage·Edge Function 변경이나 통계 발행은 수행하지 않는다. 기존 공개 통계에 2027이 없으면 문항 통계 준비 중 안내만 표시하며 채점·정답표는 정상 동작한다. 정적 정답 추가로 개발자 통계 카탈로그는 기존 76개에서 내부 호환 키를 포함한 80개 조합으로 확장된다. 향후 통계 수동 발행 시 현재 운영 정답 등록과 새 카탈로그의 일치를 먼저 검토해야 한다. 이 작업에서 운영 통계를 갱신하지 않는다.

웹의 실서비스 채점 개방에는 변경 코드의 배포가 필요하다. `main` push는 배포를 유발하므로 명시적 요청 후 버전 갱신·품질 검증을 거쳐 수행한다.
