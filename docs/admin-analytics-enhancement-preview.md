# 관리자 이용통계 고도화 화면 미리보기

후속 상태: 사용자가 미리보기 적용을 승인하여 [실제 앱 로컬 구현·검증](admin-analytics-enhancement-implementation.md)을 완료했다. 아래 내용은 설계/미리보기 작성 당시의 기록이며 운영 반영은 아직 하지 않았다.

작성일: 2026-10-16 KST. [설계](admin-analytics-enhancement-design.md)와 [추가 검토](admin-analytics-enhancement-review.md)를 반영한 **독립 정적 미리보기**다.

- 화면: [admin-analytics-enhanced.html](previews/admin-analytics-enhanced.html)
- 스타일: [admin-analytics-enhanced.css](previews/admin-analytics-enhanced.css)
- 가상 자료·동작: [admin-analytics-enhanced.js](previews/admin-analytics-enhanced.js)

실제 앱의 `src/`, 라우트, 배포 설정, 패키지, Supabase를 변경하지 않는다. API·SDK·쿠키·localStorage를 사용하지 않는다. HTML의 CSP `connect-src 'none'`으로 서버 연결을 차단한다. 모든 회원·수치·발행 세대·앱 버전별 성과·운영 주석은 가상 예시다. 설계 문서에 기록한 실제 운영 수치와 섞지 않는다.

## 확인할 화면

| 탭 | 반영한 내용 |
|---|---|
| 개요 | 기존 6개 카드, 구간 일평균 추이, 변화의 근거와 상세 이동, 회원 수×회원당 채점 분해, 수집 품질, 복습, 오늘 잠정 현황, 최근 활동, 버전 비교 예시 |
| 기능 | 사용 가능→실제 노출→실행→결과 확인, 기능·이용 화면 전환, 노출 미관측 실행 분리, 교차 이용, 진입 목적별 도달 |
| 채점 | 입력 흐름/실행 집계 전환, 미지원 과목 안내, 과목별 저장 응답, 저장 대기와 결과 표시 시간, 기기별 분모 |
| 회원/재방문 | 정확한 D7과 W1 구분, 미성숙/관측 공백, 채점 후 복습, 반복 이용 간격과 1회 이용자, 이용일 분포, 현재 보관 스냅샷 |
| 회원 활동 | 가상 회원 검색·선택·해제와 개인 활동. 선택은 전체 통계를 변경하지 않음 |
| PWA | 실행 지표·채널 교집합·설치 신호 분리, PWA 최초 이용 코호트, 별도 푸시 스냅샷 제안 |
| 관리자 조회 이력 | 가상 감사 이력과 조회 종류 필터 |

상단에서 7일/30일/6개월/1년, 실행 채널, 직전 비교를 전환한다. 장기 범위에서 상세로 이동하면 최근 90일 교집합을 안내한다. 지표 정의는 별도 대화상자에서 확인한다.

`미리보기 상태`에는 충분한 자료·수집 초기·관찰일 공백·정상 0건·조회 오류·권한 만료가 있다. 수집 초기의 장기 미발행을 자료 0건으로 표시하지 않는다. 권한 만료에서는 이전 개인 자료와 선택 상태를 제거한다. 새로고침과 재시도는 가상 자료 상태만 갱신한다.

대기시간·기능 노출·실행 앱 버전·서버 저장 확정은 추가 계측이 필요한 제안이며 현재 운영 API가 제공한다고 가정하지 않는다. 미리보기의 UI 변경 범위를 검토한 뒤 실제 앱 적용을 별도 승인한다.

## 열기와 검증

HTML을 로컬 브라우저에서 직접 열거나 정적 서버로 제공한다.

```sh
python3 -m http.server 4187 --bind 127.0.0.1 --directory docs/previews
```

주소: `http://127.0.0.1:4187/admin-analytics-enhanced.html`

전용 검증:

```sh
npm run test:e2e -- --config playwright.analytics-preview.config.ts
```

전용 설정은 `e2e-previews/`의 이 정적 미리보기만 검사하며 기존 앱의 `e2e/` 검사에는 추가하지 않는다. Vite·실제 앱·환경 변수·운영 API를 시작하지 않는다. 320/390/1280px의 7개 탭, 가로 넘침, 기간/추이/필터, 입력 흐름·실행 분리, 관찰 공백과 미성숙, 기능 노출 분모, 회원 선택·해제·권한 만료, 키보드 탭·지표 대화상자, 외부 요청 없음을 검사한다.

이 검증은 화면 제안을 위한 것이며 실제 집계 SQL·운영 권한·부하를 검증하지 않는다. 실제 앱과 빌드 대상이 바뀌지 않아 전체 빌드 및 운영 공개 통계 조회는 실행하지 않는다. 검토가 끝나면 미리보기·문서·전용 검증을 한 단위로 커밋할 수 있다. main push는 배포를 유발하므로 별도 요청 없이 실행하지 않는다.
