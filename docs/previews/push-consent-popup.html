제안하는 표시 규칙
  • 회원·비회원 구분 없이 일반 서비스 접속 3초 뒤 자동 표시. 권한 허용 기기는 등록 상태 확인 후 미등록일 때 표시.
  • ‘나중에’·닫기·Esc·바깥 클릭은 같은 동작: 이 브라우저에서 7일 동안 자동 표시하지 않음.
  • 등록 완료·등록 대기·7일 유예 중에는 자동 표시하지 않음.
  • 차단·설치 필요·등록 오류도 설정/설치/재등록 안내를 자동 표시.
  • 동의 버튼을 누른 뒤에만 실제 브라우저 권한 요청. 허용하면 팝업은 바로 닫고 등록은 계속 진행.
  • 상단 알림 링크 없이 팝업으로만 진행. 가입·로그인은 필요 없음.
7일 간격은 사용자 요청을 반영했습니다. 실제 앱에서도 팝업과 7일 유예를 적용합니다.
