METRIC GUIDE

숫자를 읽는 기준

회원 · 세션 · 실행

회원은 기간 내 고유 계정입니다. 비회원은 세션으로 구분하며 회원 수와 합쳐 사람 수로 표시하지 않습니다. 두 과목을 함께 채점하면 실행은 1회, 저장 대상은 최대 2개입니다.

카드와 그래프

카드는 선택 기간 전체의 고유 수입니다. 그래프는 구간의 일평균이며, 날짜별 고유 회원 수를 더해 기간 회원 수로 사용하지 않습니다.

D7과 W1

D7은 최초 핵심 이용일의 정확히 7일 뒤입니다. W1은 D+7~D+13의 재이용입니다. 해당 관찰 기간이 완료되고 자료가 가용한 회원만 분모에 포함합니다.

기능 사용률

기능이 사용 가능했고 실제 화면 노출까지 관측된 진입을 분모로 계산합니다. 노출이 관측되지 않은 실행은 별도 집계합니다.

미계산 상태

0건은 정상 관측된 0입니다. 수집 전·공백·미성숙·지원하지 않는 필터·조회 오류는 서로 다른 상태로 표시합니다.

새 계측이 필요한 분석

대기시간, 기능 노출, 실행 앱 버전, 서버 저장 확정은 추가 수집이 필요한 제안입니다. 이 미리보기의 수치는 모두 가상이며 현재 운영에서 제공되는 자료가 아닙니다.
